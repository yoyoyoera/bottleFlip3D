# Bottle Flip 3D

4명이 한 테이블에 둘러앉아 물병을 던져 세우는 물리 파티 게임.

- 기획서: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)
- 던지기 손맛 프로토타입: [`prototype/`](prototype/)

## 프로토타입 실행

**웹 프로토타입**: 브라우저에서 실행한다. 온라인 모드는 정적 HTML 공유만으로는 동작하지 않고 아래 Node 서버가 필요하다.

**Windows에서 내 PC로 실행**: 저장소를 받은 뒤 `start.bat`을 더블클릭한다. Node.js가 없으면 winget으로 설치하고, 첫 실행 때 `npm install`을 한 뒤 브라우저를 연다.

직접 실행하려면:

```bash
cd prototype
npm install
npm run dev      # http://localhost:5173
npm test         # 물리 코어 테스트 (결정성, 유체 효과, 성공 구간)
```

### 모드
- **연습**: 혼자 무한으로 던지기. 성공률, 연속 성공, 최고 연속, 뚜껑 착지 기록
- **멀티 (한 PC)**: 2~4명이 테이블 네 자리에서 번갈아 던지기. *먼저 성공*(누군가 목표 점수에 닿으면 끝) 또는 *꼴등 가리기*(목표에 닿은 사람은 빠지고 마지막 한 명이 꼴등). 목표 점수 1~5, 뚜껑 착지 2점(옵션, 기본 켬)
- **온라인**: Host로 방을 만들고 같은 서버에 접속한 친구가 Join에 6자리 코드를 입력한다. 2~4명, 방장만 시작/재시작. 맵·병·유체는 방장의 메뉴 설정을 공통 적용한다. 누군가 나가면 현재 경기를 끝내고 대기실로 돌아가며, 방장이 나가면 남은 첫 참가자가 방장을 맡는다.
- **멀티 공통**: 매 턴 15초. 던지기 시작 후에는 착지까지 기다리고, 던지지 못하면 0점으로 다음 차례. 강도 바와 초록 성공 구간은 연습에서만 표시한다. 경기 중 커스터마이즈·튜닝은 잠긴다.

### 조작 (1인칭)
- **마우스 좌우**: 눈앞에 쥔 병이 손째로 좌우로 움직이고 시선도 따라간다. 던지는 방향은 내 눈에서 병을 바라본 방향 (사선 던지기)
- **마우스 상하** (누르지 않은 상태): 위 = 멀리, 아래 = 가까이. 가까이 들수록 각도를 더 줘야 테이블에 떨어진다
- **스크롤** (또는 ↑/↓, Shift+스크롤은 5°씩): 던지는 각도 0~45°. 기울일수록 멀리 가고 손목 스냅(회전)이 세지지만 성공 구간이 좁아진다
- **누른 채 위로 끌기**: 끈 거리만큼 힘이 찬다. 놓으면 던진다 (우클릭/Esc 취소)
- **Space** 길게 누르기: 파워가 0에서 최대까지 왕복한다. 놓으면 던진다
- **R**: 다시 세우기
- 점선 = 예상 궤적, 노란 원 = 착지 예상 지점
- 연습 모드 오른쪽 아래 파워 미터의 **초록 띠** = 지금 조합(병, 유체, 채운 양, 맵, 각도)에서 서는 파워 구간

### 온라인 서버 실행

Node.js 22.12 이상 권장. 개발 중에는 `npm run dev` 하나로 웹 화면과 온라인 서버를 함께 실행한다.

```bash
cd prototype
npm ci
npm run dev -- --host 127.0.0.1
# 같은 PC의 브라우저 탭 2개로 Host / Join 테스트
```

같은 Wi-Fi의 다른 PC와 테스트할 때는 `npm run dev -- --host 0.0.0.0`으로 실행한 뒤, 모두 서버 PC의 사설 IP 주소(예: `http://192.168.0.10:5173`)로 접속한다. 운영체제 방화벽의 해당 포트 허용이 필요할 수 있다. `localhost` 주소는 친구의 PC와 공유할 수 없다.

배포용 실행은 `npm run build` 후 `npm start`. 기본 주소는 `127.0.0.1:5173`이고 `HOST`, `PORT` 환경변수로 바꾼다. 인터넷 친구끼리 플레이하려면 이 Node 서버를 WebSocket 연결을 지원하는 HTTPS 호스팅에 배포해야 한다. 아직 공개 서버나 Steam 네트워크 연동은 포함하지 않는다.

서버가 고정 시간 간격으로 물리를 계산하고 위치·회전·유체 대리 입자를 초당 20회 보낸다. 클라이언트는 이를 보간해서 보여주며 점수를 보내지 않는다. 서버가 차례, 입력 범위, 타이머, 착지와 승리를 검증한다. 접속 복원과 진행 중 참가, 플레이어별 병 설정은 후속 개발 범위다.

### v0.2 회전 조정

병 무게와 높은 충전율에 따라 출발 손목 회전을 줄였다. 기본 물 30% 페트병의 기존 조작감은 유지한다. 동일한 테스트 입력(파워 1, 높이 0.95m, z=0.5)에서 유리병 30%는 약 2.76→1.35회전, 페트병 100%는 약 1.77→1.18회전이다. 실제 유체 역학의 정밀 재현이 아닌 플레이 감각 보정이다.

### 구조
| 파일 | 역할 |
|---|---|
| `src/physics.js` | 게임플레이 물리 (병 강체 + 유체 대리 입자, 고정 스텝, 결정적). 렌더와 무관해서 Node에서도 돈다 |
| `src/config.js` | 병, 유체, 맵, 던지기 튜닝 값 |
| `src/shape.js` | 병 형상 (물리와 렌더가 공유) |
| `src/bottleView.js` | 병, 라벨, 액체(클리핑 수면), 탄산 거품 렌더링 |
| `src/world.js` | 4인 테이블과 맵 테마 |
| `src/guide.js`, `src/guideWorker.js` | 성공 구간 계산 (백그라운드 워커에서 실행, 화면 끊김 방지) |
| `src/rules.js` | 멀티 룰 (점수, 모드, 차례, 순위). 화면과 무관한 순수 로직 |
| `src/main.js` | 메뉴, HUD, 입력(플릭/충전), 게임 루프 |
| `src/turnClock.js` | 프레임 속도와 무관한 15초 피치 클락 |
| `src/network.js` | 브라우저 WebSocket 연결 |
| `server/multiplayer.js` | 온라인 방, 입력 검증, 서버 물리·점수 판정 |
| `server/index.js` | 빌드한 웹 화면과 온라인 서버를 함께 실행 |
